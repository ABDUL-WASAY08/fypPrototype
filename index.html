FAQ

Questions? We've got answers.

What is TOM?+
TOM (Train Optimal Model) is an AI-powered GitHub intelligence platform and developer-recruiter marketplace. It combines RAG-based code retrieval, automated documentation, code-quality scorecards, and a peer-to-peer marketplace for custom AI models.
How does the marketplace work?+
Developers can train and list custom domain-specific models on TOM's Marketplace. Buyers can browse, test, and deploy models directly into their CI/CD pipeline. All transactions are handled via smart contracts with built-in verification.
Is TOM open source?+
The core TOM engine is open source (MIT license). The Marketplace, advanced analytics, and premium training pipelines are available under a commercial license with a free tier for individual developers.
What languages are supported?+
TOM supports 20+ programming languages natively, including Python, JavaScript, TypeScript, Rust, Go, Java, C++, Ruby, and more. Language-specific analyzers ensure deep semantic understanding for each ecosystem.
